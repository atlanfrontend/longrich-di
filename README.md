# Каталог Longrich 2026 — сайт

**Адрес: https://longrich-di.github.io**

Версия с поиском и фильтрами: https://longrich-di.github.io/katalog

---

## Файлы

- `index.html` — простой список: всё подряд, ничего нажимать не нужно
- `katalog.html` — версия с поиском и фильтрами по разделам
- `data.js` — все 48 товаров, цены и описания. **Правится здесь.**
- `img/` — 49 фотографий товаров

## Как обновить сайт

Правите файл в этой папке и:

```
cd ~/Desktop/longrich-catalog/longrich-di
git add -A
git commit -m "обновил цены"
git push
```

Через минуту изменения появятся на сайте. Ссылка не меняется.

## Телефон

Номер WhatsApp задан в начале скрипта в `index.html` и `katalog.html`:

```js
const PHONE='77479176369';
```

Меняется в обоих файлах, без плюса и пробелов.

## Свой домен

Если захотите адрес вида `longrich.kz`: купить домен, затем в репозитории
Settings -> Pages -> Custom domain вписать его, а у регистратора домена
добавить CNAME на `longrich-di.github.io`.
